# Open WebUI 浏览器助手（CK）隐私政策

更新日期为 2026 年 11 月 26 日。适用于由 CK（GitHub 账号 `someone97421`）维护的 Chrome 扩展 0.0.22。

使用你自行部署的 Open WebUI 时，开发者不会收到你的登录凭据、浏览记录、网页内容或对话。扩展在本机保存设置，引用和任务数据由你配置的服务及其中继处理。该服务可按其配置调用模型提供方。

## 使用哪些数据

| 功能 | 涉及的数据及用途 |
| --- | --- |
| 连接自己的服务 | 扩展保存服务地址、浏览器配置标识、显示名称和偏好。配套服务使用你的登录会话、账号标识和短期绑定凭据，将网页引用与任务送到相应浏览器。 |
| 在侧栏登录 | 侧栏加载你指定的 Open WebUI。你在登录页提交的邮箱、密码和验证信息由该服务处理。若在扩展选项中选择「记住密码并保存」，扩展会按服务地址，在当前 Chrome 配置的扩展 IndexedDB 中保存邮箱、自动登录偏好和用 AES-GCM 加密的密码。加密密钥不可导出，保存在同一扩展数据库。填充密码时，扩展会解密并填入对应服务的登录表单；开启自动登录后会尝试提交该表单。 |
| 选择网页引用 | 连接侧栏时，扩展读取浏览器中可引用标签页的标题、网址和标识，向侧栏页面提供 @ 候选。右键引用会传递网页或选文，拖动准星会传递所选元素的文字、定位信息、部分 HTML 及上下文。引用先进入对话草稿。 |
| 执行网页任务 | 侧栏连接后会自动接管支持的当前页。任务可以通过 Chrome 调试接口读取页面、截图、表单和调试信息，执行点击、填写、导航等操作。人工接手或示范任务可能处理用户的交互及录制数据。内容可能包含网页中的个人通信、账号、位置、健康或财务信息，取决于用户打开的页面和发起的任务。 |

## 数据去向

网页引用和调试结果通过用户配置的服务及其中继传递。发送对话或执行工具任务时，该部署可能将相关内容发送给管理员或用户选择的模型提供方。部署运营者控制服务器上的访问、日志和数据保留。扩展支持 HTTP 和 HTTPS，远程部署宜使用 HTTPS，以保护传输中的账号和网页数据。

扩展处理上述数据以提供侧栏聊天、网页引用、浏览器操作及故障诊断。开发者不出售这些数据，不用于广告、信用评估或与这些功能无关的用途。希望联系开发者时，可使用 Chrome Web Store 条目中列出的开发者联系方式。请勿在反馈中附上密码、绑定令牌或私人聊天记录。

## 如何控制和删除

- 在扩展选项的「Open WebUI → 侧栏登录」关闭自动登录并保存，或选择「清除登录信息」，删除当前服务的已记住账号和密码。退出 Open WebUI 可结束当前登录会话。
- 在设置中关闭网页元素拾取，可停止使用准星捕获。发送消息前可以移除草稿中的引用。需要停止浏览器操作时，可以收回标签页或停用扩展。
- 删除扩展会清除该扩展在当前浏览器配置中的本地数据。已经发送到自托管服务或模型提供方的数据需在相应服务中管理。可通过 Open WebUI 删除聊天，或联系部署管理员处理备份及日志。
